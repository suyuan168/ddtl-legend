# 音频清单（用户自制，做好放进 `ddres/Wav/`）

所有音频必须是自己做的或有明确商用授权的（不能用原版传奇的音乐音效）。

## 格式
- 音效：`.mp3`（或 `.ogg`），单声道，44.1kHz，响度统一约 -16 LUFS，开头不要留空白。
- 背景音乐：`.mp3`，立体声，128–192kbps，能无缝循环（首尾接得上）。
- 文件名用下面的英文名，我按名字接进游戏。

## 背景音乐（5 首）
