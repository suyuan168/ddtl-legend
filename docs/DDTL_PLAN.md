## 三、画图依赖的格式（我们的美术怎么接进去）

- 原客户端读 WIL/WIX 图库：8 位索引色，加原版固定的 256 色调色板，每张图带 px/py 偏移。
- 动作表在 `frontend/actor/actorData.mjs`：
  - 人物每个外观 600 帧，各段动作的起止帧为：站 0、走 64、跑 128、砍 200、施法 392、受击 472、死 536。
  - 每段按 8 个方向排，帧号 = 起始帧 + 方向 × (帧数 + 跳过帧)。
  - 怪物按 MA9–MA52 动作表排，NPC 每个外观 60 帧。
- 地图图块是 48×32 的斜视角格子，分大图块、小图块、物件三层。

**接法：不用 WIL，改成 PNG 图集 + JSON。**
- 写一个 `ImageLib`，和 `WIL` 类接口一样（按帧号取 canvas、px、py），数据来自 `图集.png` + `图集.json`（帧号对应 x、y、w、h、px、py）。上层动作表代码不用改。
- 用 PNG 是因为原版固定的 256 色调色板会把我们的图压色。
- 打包脚本 `tools/pack-lib.mjs`：
  - 输入 GPT 出的动图（5 个方向：下、右下、右、右上、上）。
  - 左边 3 个方向（左下、左、左上）自动镜像生成。
  - 按动作表帧号排好位置，自动算 px/py（脚底对齐格子中心），输出图集。
- 武器、头发不分层，直接画在身上；衣服换颜色由打包脚本出几套色。
- 怪物只出下、侧、上 3 个方向，其余镜像或复用。
